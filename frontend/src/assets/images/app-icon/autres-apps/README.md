# Icônes de remplacement (Dock) — même DA sombre que l'icône Gravisterie API

- `fusion360-sombre-macos.icns` / `.png` — Autodesk Fusion
- `lightburn-sombre-macos.icns` / `.png` — LightBurn
- `source/` — HTML de composition (Chrome, 1024×1024, fond transparent).

Appliquer : Finder → clic droit sur l'app → Lire les informations → glisser le .icns sur la petite icône en haut à gauche de la fenêtre.
Retirer : même fenêtre, cliquer l'icône puis Édition → Supprimer (ou Cmd+X).
Attention : une mise à jour de l'app peut remettre l'icône d'origine ; il suffit de réappliquer.
Fusion : ~/Applications/Autodesk Fusion.app ; LightBurn : /Applications/LightBurn.app.
